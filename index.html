Nama Shift Jam Mulai Label Waktu Durasi Kategori Kode Outlet Urutan Status Aksi
Memuat daftar shift…

💡 Kategori: Management (tampil utk karyawan divisi Management) • Operasional (tampil utk divisi Operasional) • Special (tampil utk karyawan di outlet tertentu, sesuai Kode Outlet).
💡 Kode Outlet diisi kode outlet (mis. SCH, UII) untuk shift khusus outlet. Kosongkan untuk shift umum semua outlet.

Editor Template Surat Perjanjian Kerja

v-
Target Divisi Template

Pilih divisi lalu edit field di bawah. Setiap divisi bisa punya template berbeda (klausul, denda, jam kerja). Karyawan otomatis dapat template sesuai divisinya — kalau divisi belum punya template khusus, fallback ke ALL.

Memuat daftar template...

✓ Form Cepat: Isi field di bawah — sistem otomatis menyusun HTML SPK lengkap. Data karyawan (nama, NIP, gaji, alamat, dll) tetap otomatis dari data masing-masing karyawan saat SPK ditampilkan. Tidak perlu sentuh HTML.

Memuat form...

"Salin HTML" akan memindahkan hasil Form Cepat ke Editor HTML Lanjutan untuk fine-tuning.

📋 Placeholder yang tersedia (otomatis diganti data karyawan saat SPK ditampilkan):
{{nomor}} {{tahun}} {{employee_name}} {{nip}} {{tempat_tanggal_lahir}} {{alamat}} {{email}} {{nomor_ktp}} {{phone}} {{status}} {{jabatan}} {{uraian_pekerjaan}} {{jam_kerja}} {{gaji_pokok}} {{tunjangan_makan}} {{tunjangan_transport}} {{tunjangan_jabatan}} {{uang_kerajinan}}

Gunakan tag HTML standar (<h3>, <p>, <ul>, <table>, <strong>).

Editor teks polos (HTML). Untuk format rumit, edit di editor HTML eksternal lalu paste di sini.

⚠️ Peringatan: Setiap klik "Simpan & Versi Baru" akan membuat versi baru + menonaktifkan versi lama. SEMUA karyawan akan diminta menyetujui ulang SPK saat membuka Profile berikutnya. Pastikan perubahan sudah final sebelum simpan.
